# Research results

This directory is for numerical results and figures generated by the notebooks. The `.gitignore` currently ignores generated `results/*.csv`, `results/*.png` and `results/*.pdf`, so files may exist only in the environment where the notebook was run.

## Results currently visible in the main notebook

The committed [20-ETF notebook](../data/03_twenty_etf_exploration.ipynb) contains saved outputs for:

- January 2025 exact exhaustive-search and greedy portfolio comparison, plus **one** QAOA quick-run comparison.
- Ten QAOA trials at circuit depth 1 and ten at depth 2, both on **the same January 2025 decision problem**.
- Six July–December 2024 monthly classical-versus-greedy comparisons.
- 120 historical Random Forest forecasts and their accuracy checks.
- Quantum objective-coefficient and phase-angle consistency checks.

The above outputs are **saved notebook results**, not automatically regenerated by viewing this repository. Restart the kernel, run all cells, and check that output numbers still match before final submission.

## Common output names

- `quantum_vs_classical_20_etfs.csv` — single January 2025 algorithm comparison (written at notebook working directory root).
- `results/qaoa_experiment_results.png` — three-panel repeated-QAOA experiment figure.
- `results/historical_classical_comparison.png` — six-month exhaustive-versus-greedy figure.
- `results/walk_forward_forecasts.csv` — historical ETF forecasts.

If results are needed as publicly downloadable GitHub artifacts, explicitly add the final validated copies after reviewing the ignore rules. Avoid committing temporary exports, duplicate plots, or synthetic-demo outputs as empirical findings.

## Remaining research limitations

The 20-ETF notebook does **not yet** establish results for increasing ETF counts, multi-month QAOA portfolio backtesting, or a statistical Sharpe-ratio comparison. Do not use results from older demonstration notebooks to imply those tests were completed for the current main experiment.
